# Image Size Tool

Source-only mirror of TheLustriVA/ComfyUI-Image-Size-Tools at
1cb252cba790c4a2f7ba1dce2bc1b7465980c39f (MIT). All15 original files and
their Git modes/blobs are retained. No pack, SDK, scientific import, test,
manifest generation or runtime qualification ran during source preparation.

All six original IDs/classes/display names, category, ordered options, defaults,
input/output names and counts remain. The complete original image_size_nodes.py
is retained byte-exact as _original.py; the public V2 adapters call its original
methods. The five preset calculators request no permissions. ImageSizeDetectorNode
uses the existing public ImageRef.raw boundary and requests raw, then calls the
unchanged original method. It reads the same four-dimensional tensor shape;
its output remains width then height. No new API, host write, model or production
scientific dependency was added. The raw declaration requests authority only.

The original WAN21 methods calculate and return the two halved outputs for both
values of halve_resolution; the boolean is ignored by the original body. That
behavior is intentionally preserved. The original preset labels, order and
numeric tables are unchanged. Python's mirror runtime declaration is narrowed
from >=3.8 to >=3.13,<3.14; project version0.3.4 is retained. The extension
entrypoint is added alongside the original registration mappings. Existing
canonical pyi42b9/d.tsabf141 are reused with genuine generation provenance.
