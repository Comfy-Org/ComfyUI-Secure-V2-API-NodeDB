# Resolution and Join native qualification

The retained actual Mac runs compare unchanged converted algorithms with the
genuine original packs and real SDK. Resolution has 1,033 execution and 1,033
validator comparisons, 33 denials and three wrong-result controls. Join has 704
full-original comparisons plus 704 component crosschecks, seven denials and six
controls. Normal generation, canonical patch generation and both pristine-tree
replays passed. Exact source and selected environment bindings are retained.

This is a source qualification update to two existing corpus identities. It
does not certify whole packs, Guest/public-executor/frontend/autogrow behavior,
browser behavior, production admission or runtime readiness. The older test
files use manual manifest expectations that differ from the new genuine normal
encoder. Their historical suite totals are not carried forward as current
passing assertions. The source reports identify those unrefreshed checks.

The first sealed publication packet and its review are preserved. Its stale
manifest hash and historical test wording were corrected in a docs successor;
runtime and genuine generated manifest bytes remain unchanged. Canonical pairs
were regenerated and replayed for the documentation-only change. Delivery ZIP
bundles are deliberately excluded; the canonical JSON and diff are committed.
Registry source adoption requires a separate operator window.
