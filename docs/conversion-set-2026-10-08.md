# October 8 conversion source snapshot

This branch retains the 193-entry baseline and publishes the 44 current catalogue additions, for 237 catalogue entries. Of those additions, 39 whole packs have this coordinator’s independent bounded local acceptance; 14 were completed since midnight October 8. The remaining five have their existing reports and are not added to that completion count.

Every added pristine/V2 tree is copied byte-for-byte with modes. Its exact JSON/diff pair reconstructs V2, and its deployment ZIP is checked. The accompanying JSON inventories all published files and identifies any regenerated ZIP.

These are source and artifact publication checks. The pack reports retain runtime, workload and native behavior qualifications. This is not a Cloud deployment, Linux/GPU certification, or new fresh-checkout execution proof. SeedVR2, Wan and LoRA Manager work in progress is excluded. Shared runtime and original dirty trees are not committed by this snapshot.
