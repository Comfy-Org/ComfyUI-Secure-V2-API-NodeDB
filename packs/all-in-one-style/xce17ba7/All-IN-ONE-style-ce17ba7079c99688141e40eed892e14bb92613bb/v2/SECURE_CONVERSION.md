One backend node, `ComfyUIStyler`; no frontend, routes, models or vendor services.
Complete historical Git source ce17ba7079c99688141e40eed892e14bb92613bb is
preserved as V1, including project version 1.0.0. Official registry release
1.0.1 has identical 25 code/resource/license/readme files; its pyproject differs
only in publication version, description and spacing. This is not an exact
26-file release capture. See source-provenance.json for the precise delta.

The native prompt_styler.py and all 21 JSON catalogues remain byte-identical.
Their native glob and JSON insertion behavior determines options. The wrapper
adds V3 schemas and pre-operation profile guards, not prompt algorithms.
Order of supplied menu keyword arguments, duplicate template behavior,
all literal {prompt} replacements, negative-prefix order, logging and admitted
native errors remain source-exact.

The explicit profile is the pinned immutable bundled catalogue: 21 JSON files,
10,277 source rows. Import verifies exact filenames, bytes/hashes and bounded
scans before the native loader. No externally edited catalogue, authored
library import, user filesystem authority or Cloud continuity is claimed.
Resource checks assume the admitted read-only pack root; they are not a
hostile-parent concurrent-mutation certification.

Input and projected combined output text are limited to 65,536 UTF-8 bytes.
Menu selections are plain bounded strings; cumulative replacement/join/log
work is limited to 16,777,216 projected bytes. Refusal happens before native
replace/format/print. Unsupported host objects are not materialized.

SDK_REFS=False and permissions=[]: plain strings/boolean only, zero raw,
inspection, assets, models, network or output permissions. Workflow selections
remain authored graph values; the fixed template library is immutable.
Python 3.13 inherited Mac development runtime, stdlib only, no profile hash.
No sealed/Linux/Cloud deployment or editable-library parity claim.
