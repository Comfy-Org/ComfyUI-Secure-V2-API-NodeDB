# Flux Prompt Generator conversion

The complete single registered node keeps the original prompt generation, native random choices, clean-up regexes, BREAK_CLIPL/BREAK_CLIPG extraction and deterministic per-call seed behavior. It has no frontend extensions, routes, services, model weights or durable user state. All 31 bundled JSON files are retained and hash-verified before native import. The unused photo_framing resource is preserved. This profile uses immutable bundled catalogues; externally edited JSON catalogues are outside the accepted scope.

The original node declares one prompt STRING socket but returns five internal values. All five raw values are preserved. Native legacy merge caches five columns; the canonical V3 OUTPUT_IS_LIST mask exposes the one declared prompt socket. Its value is exact, and no extra public sockets are invented. Surplus undeclared column/cache access is not an interoperability promise.

The source seed schema uses random.randint(0,30000) each time INPUT_TYPES is evaluated. The static manifest captures one actual source boot sample, recorded in bundled-data-profile.json. This is a published boot default, not a fresh random default for each schema query. Execution still uses the source local Random(seed) and does not alter ambient RNG state; IS_CHANGED remains NaN.

The sole source-code deletions are an unused runtime pip installer and its sys/subprocess imports. No caller reaches that helper in the source. Original executable algorithms and data loader remain AST-exact. No algorithm moves to a shared provider. The public ComfyNode uses zero SDK grants, and no network or raw capability is supplied.

Admission requires plain integer seeds up to 64 bits and plain string fields with cumulative 4096 UTF8 bytes. Before native generation it projects source random choices, lighting multiplicity and literals against an 8192-byte text/regex workload. The four string results have a cumulative 65536-byte publication ceiling. These are conservative workload bounds, not an OS heap or arbitrary-regex complexity guarantee; the pack executes only its fixed native patterns.

Tests compare every literal combo option plus random/disabled, all five raw native results, declared prompt consumption, Unicode/BREAK behavior, seeds, resource/source identity, schema/NaN fingerprint, before-operation refusals and recovery. Actual fresh required sandboxed guests and CloudExecutionBackend outer execution carry only scalars. Complete manifest proxies and pristine-plus-pair/ZIP reconstruction are checked. Run with explicit COMFY_CORE_ROOT, MANY_FLUX_OVERLAY_ROOT and MANY_FLUX_FRONTEND_ROOT, PYTHONDONTWRITEBYTECODE=1 and COMFY_GUEST_SANDBOX=require. The current evidence is bounded Mac-local Python3.13 development, not sealed image admission, Linux/GPU or Cloud deployment proof.
