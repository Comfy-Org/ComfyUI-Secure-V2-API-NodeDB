The pure list, axis, text, and label algorithms remain pack-side. Input text
files are selected and read only through the managed `assets` catalogue.
`XY Grid Accumulator` uses the bounded D29 `image.accumulate` operation, asks
the host UI service to publish previews, and emits a signed graph expansion
only to the separately sealed `GridAnnotation` and `ImagesGridByColumns`
Secure Nodes proxies. No tensor, filesystem path, or live model object is
stored in guest globals.

The frontend keeps the Reset button, accepted-run index advancement, and total
image readout through the V2 widget and queue lifecycle. The legacy global
`graphToPrompt` monkey-patch is unnecessary because V2 registers the stable
backend input name `index` directly.
