# Multi Bool Panel

## 概要

1ノードで複数のbooleanトグルを管理できるComfyUIカスタムノードです。
ノード自身の名前（タイトル）を接頭語にして操作対象ノードを自動検出し、各対象にon/offトグルを表示します。出力ソケットはありません。

## インストール

**ComfyUI Manager の場合**: カスタムノードマネージャーで「Multi Bool Panel」を検索してインストール（ComfyUI-Managerレジストリ登録後）。

**git clone の場合**:
1. `ComfyUI/custom_nodes/` で `git clone https://github.com/solidlime/ComfyUI-MultiBoolPanel` を実行
2. ComfyUIを再起動します
3. ノード追加メニューで「Multi Bool Panel」を検索して追加します（カテゴリ: `Logic`）

**手動コピーの場合**: このフォルダ（`MultiBoolPanel`）を `ComfyUI/custom_nodes/` にコピー → ComfyUI再起動 →「Multi Bool Panel」を検索して追加

## 使い方

1. 「Multi Bool Panel」ノードを追加します
2. パネルのタイトルをダブルクリックして、接頭語にしたい名前に変更します（例: `A`）
3. タイトルが `A:名前` で始まるノードが自動的に操作対象になり、パネル内に「名前」のリストとトグルスイッチが表示されます
4. トグルを切り替えると対象ノードに即時適用されます

例:

| パネルのタイトル | 対象になるノードのタイトル | パネル内の表示 |
|---|---|---|
| `A` | `A:高画質`、`A:顔修正`、`A:背景除去` | 高画質 / 顔修正 / 背景除去 の3行 |

## モード

`mode` ウィジェットで適用方法を選択します:

- `widgets`: 対象ノードの最初のbooleanウィジェット（チェックボックス）を切り替えます。booleanウィジェットが無いノードの行はグレー表示され操作できません
- `bypass`: 対象ノードのbypass状態を切り替えます
- `mute`: 対象ノードのmute状態を切り替えます

トグルの意味は「スイッチ」と同じです: **ON = 対象が通常実行、OFF = バイパス/ミュートを適用**（widgetsモードではON = チェック有効）。

トグルはクリックした瞬間に適用されます。トグル状態はワークフローに保存されます。

## 制限・注意

- 操作対象は最大20件まで表示されます（超過分は「他N件」と表示）
- 対象の照合は「パネルのタイトル + `:`」の完全一致です（大文字小文字は区別されます）
- パネル自身は操作対象になりません
- ノード追加・削除・リネームは自動で反映されます
