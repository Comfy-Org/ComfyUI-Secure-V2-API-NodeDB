## Evidence notes

- `WanVideoDiffusionForcingSampler` error-path release, check 3. r1 (forcing-leakfix-r1, handoff 1e6d4d76..., preserved FAIL) passed unipc parity, Euler error parity and "transformer weakref dead after gc", and FAILED "no retained owner/sampler frames" because that scan ran inside the event-loop step still delivering the error: those frames were held only by asyncio's in-flight Future, not by pack code. r2 (forcing-leakfix-r2, handoff ca91ea43..., same bytes, cases and envelope) redefined check 3 to measure what the fix is about: in that same step the weakref is dead and every live frame holds no owned state (worker frames cleared; owner transformer/pipeline/execution are None), and after the caller drops the error (two loop turns + gc) no package frames remain and the error and transformer are released. r2 passed 25/25. MERVYN accepted the redefinition (m_119fadf146); both runs are kept as evidence.
- Error release, known gap (sampler-block1-test-r1 error_release, handoff d043baf6..., preserved FAIL). A natural error raised inside the vendored nested closure `predict_with_cfg` matched the original exactly, but the converted transformer stayed alive while the error was in flight: the closure frame keeps its function, whose closure cells hold the sampler's transformer, and clearing frames cannot reach cells. It is freed once the caller drops the error. The forcing sampler shares this pattern (forcing-leakfix-r2 passed because its Euler error is raised outside the closure). A helper that empties each finished traceback frame's own cells (sampler-error-release-r2, static) is the proposed fix for rev 4.

## Refused techniques (never-do) and public replacements

| Never do | Public replacement |
| --- | --- |
| Global model eviction (`unload_all_models` / `soft_empty_cache`) - evicts other workloads' models | Host-managed memory policy; a node offloads only what it owns (e.g. the forcing sampler's `force_offload`) |
| Arbitrary host filesystem paths, `folder_paths`, writing `.pt` caches | Digest-bound SDK assets (`assets`: resolve / size / digest / read_range) and managed outputs |
| Network downloads inside nodes (hub downloads, urllib, torch.hub) | Pinned, managed asset acquisition outside the node; required-weight declarations |
| Direct CUDA/device authority or compile toggles as grants | SDK device/offload policy; device options carried as plain data; CPU fp32/SDPA fallback |
| Pickle / `torch.load` of untrusted files | SafeTensors with header validation; TorchScript only via the preserved original constructor from pinned assets |
| `trust_remote_code` / online tokenizers | `trust_remote_code=False, local_files_only=True` with bundled pinned tokenizer files |
| Importing ComfyUI internals (`comfy`, `folder_paths`, `server`) | Public `comfy_api.latest` (`io`, `sdk`) only; enforced by an import audit during discovery |
| Server routes / PromptServer messages | Execution-scoped SDK progress |
| Mutating host-owned objects across the boundary | Typed copies; aliasing is not promised |
| Stub or fake nodes, fabricated outputs, suppressed errors | Leave the node unregistered (partial) until real behavior exists |
| Path traversal in asset names (e.g. `../` in a LoRA name) | Logical names resolved under the declared roots (LoRA roots); traversal is rejected with ValueError (ruling m_ac9f50cd0f) |
| Server-pushed HTML/UI messages from a node (e.g. a LoRA metadata table) | The node's own declared UI output |

## Persistence disposition

Existing runtime KV and managed SafeTensors outputs may express bounded cache storage, but durable cloud backing, eviction/index consistency, quota/delete semantics and reuse after filesystem/worker resets are NOT proven.
