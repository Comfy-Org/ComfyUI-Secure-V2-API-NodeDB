# Post Processing conversion

All 23 registered source effects remain available through typed public IMAGE inputs and outputs. There are no frontend extensions, routes, models, services or authored-state stores. The original root monolith supplies every effect; historical split modules, example images and source resources remain in the complete tree without being executed.

The sole algorithm-file delta passes bounded managed Arial data to the existing Pillow font reader for AsciiArt. The caller provisions `input/post-processing/arial.ttf`; the adapter uses public assets.resolve/size/read_range and an in-memory file. The measured installed macOS Arial fixture is not bundled or represented as a portable licensed font. A missing or changed managed font fails visibly; same-length concurrent mutation is not an atomic snapshot guarantee.

Native quirks remain: ArithmeticBlend divide behavior, Canny/HSV BHW results despite IMAGE declarations, BW/channel/dtype errors, Kuwahara batch/index errors, Vignette nonsquare meshgrid errors, the native RNG streams of Dissolve and FilmGrain, and source zero-size failures. No casts, IMAGE layout normalization, source bug repairs or fallback algorithms are applied. Same-render random calls continue their source stream; fresh render process lifetime is separate from cross-render state retention.

Admission requires plain dense contiguous CPU Torch data without autograd. The ten recorded dtypes include source-native failing combinations; a dtype being admitted does not guarantee every source effect succeeds. Geometry is inspected before raw access. Each input and output is conservatively metered at 32 MiB, total projected copies/workspace at 256 MiB and work at one billion operations. Kernel, glyph, resize, broadcast, zero-channel and source Vignette expansion are projected before source execution. These are conservative workload limits, not a physical heap, OS allocation or GPU quota. Valid larger workloads may visibly refuse.

Python 3.13 and exact development dependency versions are declared in pyproject.toml and the measured profile. The actual required Seatbelt guests, public typed/raw/assets denial and recovery, production outer execution, native bit/dtype/shape/errors/RNG comparisons and exact pristine-plus-pair reconstruction are acceptance controls. Their runtime/source spans are hash-bound in receipts. Linux, sealed image admission, GPU, Cloud deployment, portable font licensing and unrestricted tensor layouts remain outside this profile.

Run the suite with explicit COMFY_CORE_ROOT, MANY_POST_OVERLAY_ROOT, MANY_POST_FRONTEND_ROOT and MANY_POST_ARIAL roots, COMFY_GUEST_SANDBOX=require and PYTHONDONTWRITEBYTECODE=1. The font identity and participating provider source hashes must match runtime-provenance.json. Tests use an explicitly labeled RNG reset fixture only to compare two source streams; the production pack does not reset seeds. There is no guest Internet grant.
