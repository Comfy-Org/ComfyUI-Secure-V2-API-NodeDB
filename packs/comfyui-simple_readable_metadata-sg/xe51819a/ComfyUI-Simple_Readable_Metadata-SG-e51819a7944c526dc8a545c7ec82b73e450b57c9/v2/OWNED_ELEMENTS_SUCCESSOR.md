# Owner-scoped Metadata successor

This successor starts from the exact frozen 9a42fee2 full Metadata7/5 conversion
and upstream e51819a7944c526dc8a545c7ec82b73e450b57c9. All19 pristine files,
Python algorithms, Python declaration, source resources, schemas, defaults,
permissions and all previous workload/lifetime qualifications are retained.
The historical source-provenance.json remains historical, not current evidence.

Only four runtime calls change: three Viewer mounted textarea operations now
carry the node ID retained in that instance's local state plus textDisplay;
MAX natural image dimensions carry the closure's node ID plus metadata_preview.
Ordinary element names remain unique. There is no global current-node state,
new production subscription, math change, hidden object recovery, or grant.
The owned JS declaration adds only the published scope and closed subscription
types over the retained composite. Unrelated Python/JS declarations remain.

Provider binding is the detached canonical core f5e175a, overlay2aff983 and
frontend60e1387. A first-successful-use handle belongs to the exact mounted
element; removed/replaced handles permanently refuse. Remount uses a fresh
handle. Async selection offsets remain UTF16. Subscriptions are acceptance
fixture probes only; awaited unsubscribe is idempotent and stops delivery.

Acceptance uses actual opaque worker/renderer/host transport with a test-only
node-definition registration fixture. Viewer tests execute real Copy/Paste
callbacks for two instances with ordinary names and a separate shared-alias
fixture. That alias substitution happens only in served test bytes, never in
production modules. MAX tests execute real dimension callbacks for two images.
Both cover wrong mount scope, foreign pack, unsubscribe, removal, remount and
stale-handle denial. These do not attest native website/subgraph/Cloud behavior.

Test-only adapters select the detached providers and the new artifact paths.
The retained Python pyi is checked byte-identical to f800a871, not falsely
asserted equal to later additive provider generations. Existing7/5 bounded

heap, codec universe, mutable input/output races and authenticated durable
library scope remain unproved exactly as in the predecessor. No new pack count.
