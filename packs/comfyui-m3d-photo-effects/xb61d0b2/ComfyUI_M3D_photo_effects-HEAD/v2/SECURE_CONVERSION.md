# Secure Nodes V2 conversion

Upstream: `https://github.com/metal3d/ComfyUI_M3D_photo_effects`

Pinned commit: `b61d0b23eadd802beec2dad5c53d816e995f516d`

Both registered image nodes and the curve-preview extension are supported. The
NumPy/Pillow algorithms remain pack-owned under bounded raw compute. The legacy
ambient SVG widget and callback replacement are expressed as a typed mounted
canvas with additive widget subscriptions and explicit teardown. There are no
routes, files, network calls, model operations, or persistent storage.
